Sakura Project UI — Changelog
==============================

Version: UI Fix 2

FIXED
- Исправлено перетаскивание именно ШТАТНОЙ кнопки открытия/закрытия GUI библиотеки.
- Кнопка теперь определяется внутри того же ScreenGui, где находится окно клиента, вместо поиска случайной круглой кнопки во всём CoreGui.
- Добавлен нормальный drag для мыши и Touch.
- Добавлен порог движения 6 px: обычный короткий клик не считается перетаскиванием.
- Положение штатной кнопки ограничивается границами экрана, чтобы она не могла улететь за экран.

UI
- Размер основного окна оставлен увеличенным: 900x620.
- Добавлено ограничение размера окна: минимум 720x480, максимум 1200x820.
- Увеличен размер текста элементов GUI примерно на 28% для лучшей читаемости.
- Сохранено перетаскивание самого главного окна за верхнюю область.

УДАЛЕНО / НЕ ИСПОЛЬЗУЕТСЯ
- Отдельная самодельная кнопка "🌸 Menu" НЕ возвращалась.
- Логика игрового функционала не изменялась; изменения относятся к UI.
